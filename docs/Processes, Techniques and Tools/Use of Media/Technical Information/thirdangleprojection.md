# Third Angle Orthographic Projection

## What Is Third Angle Orthographic Projection?
Third angle orthographic projection is a **technical drawing method** used to represent a **3D object using a series of 2D views**. Each view shows one face of the object at **true size and scale**, without perspective.

It is the **standard projection system used in the UK and Europe**, and the one required for **A Level Product Design examinations**.

---

## Purpose of Third Angle Orthographic Projection
Third angle orthographic drawings are used to:
- Communicate precise shape and size
- Show all dimensions clearly
- Enable accurate manufacture
- Remove ambiguity from designs
- Provide technical information for engineers and makers

Unlike pictorial drawings, orthographic projection is about **accuracy, not appearance**.

---

## The Principle of Third Angle Projection
In third angle projection:
- The object is imagined to be placed in the **third quadrant**
- The object is between the **viewer and the projection plane**
- Each view is projected directly onto the plane behind the object

This results in views being placed in **logical, intuitive positions**.

---

## Standard View Layout (Third Angle)

In third angle projection, views are arranged as follows:

- **Front view** – main view, drawn first
- **Top view** – placed **above** the front view
- **Right‑side view** – placed **to the right** of the front view
- **Left‑side view** – placed **to the left** of the front view (if used)
- **Bottom view** – placed **below** the front view (rarely used)

✅ **Key exam rule**:  
**Views are placed on the same side as the face they represent.**

---

## Standard Third Angle Projection Symbol
Third angle projection is identified using a **symbol**:

- A truncated cone (side view)
- A circle (end view)
- The **circle is placed on the right**

This symbol must be included in **formal technical drawings**.

---

## Common Orthographic Views

### Front View
- Most important view
- Shows the most detail
- Chosen to best describe the object

---

### Top View (Plan)
- Shows width and depth
- Placed directly **above** the front view

---

### Side View (End View)
- Shows height and depth
- Placed to the **right or left** of the front view

Only the views needed to **fully describe the object** should be drawn.

---

## Drawing Third Angle Orthographic Projection (Step‑by‑Step)
1. Choose the **front view** (most descriptive face)
2. Draw the front view at **true scale**
3. Project construction lines vertically and horizontally
4. Draw the top view **directly above** the front view
5. Draw the side view **to the right** of the front view
6. Add visible edges using thick lines
7. Add hidden detail if required (dashed lines)
8. Add centre lines for holes or symmetry
9. Apply dimensions clearly
10. Remove construction lines

All views must align correctly.

---

## Line Types Used in Orthographic Drawing
Different line types communicate different information:

| Line Type | Purpose |
|---------|--------|
| Thick continuous | Visible edges |
| Thin continuous | Construction lines |
| Dashed | Hidden detail |
| Chain (long–short) | Centre lines |
| Thin arrowed | Dimension lines |

Correct line use is essential in exams.

---

## Dimensions in Third Angle Projection
- All dimensions are shown in **true size**
- Dimensions are placed:
  - Between views
  - Outside the object where possible
- Units are usually **millimetres (mm)**
- Each dimension should be shown **once only**

Do not scale drawings to measure — always rely on dimensions.

---

## Hidden Detail
Hidden detail:
- Is shown using **dashed lines**
- Represents edges not visible from that view
- Should only be included when necessary

Too much hidden detail can make drawings confusing.

---

## Third Angle vs First Angle Projection
| Feature | Third Angle | First Angle |
|------|------------|------------|
| Standard in UK | ✅ Yes | ❌ No |
| View placement | Same side as face | Opposite side |
| Symbol circle position | Right | Left |
| Exam requirement | ✅ Yes | ❌ No |

👉 **A Level exams require third angle projection.**

---

## Third Angle vs Isometric Drawing
| Feature | Third Angle | Isometric |
|------|-------------|-----------|
| Type | 2D technical | 3D pictorial |
| Accuracy | Very high | Good |
| Scale | True | True |
| Views | Multiple | Single |
| Manufacture | Essential | Not suitable |

Orthographic drawings are used for **making**, isometric drawings for **visualising**.

---

## Advantages of Third Angle Orthographic Projection
- Extremely accurate
- No distortion
- Suitable for manufacture
- Clear communication
- Industry standard (UK)
- Works for complex components

---

## Disadvantages of Third Angle Orthographic Projection
- Requires drawing skill
- Harder to visualise than 3D drawings
- Multiple views needed
- Not visually realistic

---

## Typical Uses in Product Design
Third angle orthographic projection is used for:
- Manufacturing drawings
- Workshop instructions
- Engineering components
- Coursework technical drawings
- Exam questions
- CAD output drawings
- Quality control documentation

It is the **most important drawing method** for manufacture.

---

## Best Practice for Exams
- Always use **third angle**
- Choose the best front view
- Align views perfectly
- Use correct line types
- Keep drawings neat and to scale
- Do not include perspective
- Add the third angle symbol where required
- Only include necessary views

---

## Exam Tips (A Level)
- Define third angle projection clearly
- State it is the **UK standard**
- Mention view placement rule
- Include the projection symbol
- Compare with first angle projection
- Use correct terminology (plan, elevation)
- Keep dimensioning clear and minimal

## Overall Summary
Third angle orthographic projection is a **technical drawing system** used to represent 3D objects accurately through **multiple 2D views**, all drawn at **true scale**. It is the **standard system used in the UK and required for A Level Product Design**, with views placed on the **same side as the face they represent**. While less visually intuitive than 3D drawings, third angle projection is essential for **manufacture, engineering communication, and exam success**, as it provides clear, precise, and unambiguous information about a product’s shape, size, and features.
